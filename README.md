## 📂 Projects Included

### 1. Electric Vehicle Population Data Analysis

**Description:** An analysis of electric vehicle population data to understand vehicle types, manufacturers, model years, electric ranges, and CAFV eligibility.

**Key Activities:**
- Data loading and initial exploration
- Handling missing values and duplicate records
- Data type correction and feature creation
- Outlier detection using the IQR method
- Filtering Tesla vehicles and high-range electric vehicles
- Univariate and bivariate analysis
- Data visualization using histograms, pie charts, bar charts, and scatter plots
- Identifying patterns and generating insights

**Libraries Used:** Pandas, NumPy, Matplotlib, Seaborn

## 🚀 How to Run the Projects

1. Clone or download this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```

4. Open Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open the required `.ipynb` file and run the cells in sequence.
6. Ensure that the relevant dataset files are available in the correct folder.
